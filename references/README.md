# 参考模板原图

本目录保存用户提供的完整参考海报，用于核对构图、标题、背景与局部滤镜效果。

## 当前状态 · 2026-10-04

- 模板 01：[Aespa 杂志海报原图](template-01/original.jpg)，2026-10-04 用户补发的第二张图片。
- 模板 02：[「画像エフェクトの組み合わせ例 7 選」原图](template-02/original.png)，2026-10-04 用户补发的第一张图片。
- `assets/` 中现有 JPG 均为人物摄影素材，不是完整参考海报。

两张图片按原始字节复制存档，未裁切、压缩或重绘。模板二当前取参考图的近黑底色、黑白人物层次、蓝粉局部滤镜与细粉色选区；按用户要求，顶部使用先锋艺术标题，不采用参考图中的 Ps 图标和教程标题。

## 存档方式

收到原图后按模板存入 `references/template-01/` 或 `references/template-02/`，保留原始图片与扩展名。文件名建议为 `original.png` 或 `original.jpg`；若有多版参考，用日期或版本后缀区分。

网站生成结果与页面截图属于验证材料，不作为原始参考图存档。参考海报不直接作为用户作品的背景素材。
