# 固定示例图库与模板验收

本目录用于保存用户提供的 `aespa.zip` 所建立的固定示例图库，以及图库清单与浏览入口。图库用于检查 Collage Poster 模板在其他照片上的表现：每完成一个新模板，或修改现有模板的构图、裁切、滤镜、素材分配与导出逻辑，从同一图库挑两张代表性照片复测。

图库与海报样式参考分开保存：`references/` 用于记录希望达到的设计样式，本目录中的照片用于检验模板适配。验收依据是照片中的人物、明暗、背景和服装细节是否在应用模板后仍然成立。

## 每个模板的必测流程

先记录模板名称、版本和日期，保存当前模板的基础预览。然后查看选定两张照片的单图结果，再使用同两张照片组合进行多图测试。每次测试记录所用的原图路径或清单 ID，确保后续可以重复同一场景。

| 场景 | 操作 | 验收内容 |
| --- | --- | --- |
| 单图适配 | 从默认海报上传一张图库照片，应用待验收模板；更换选定的另一张照片重复检查 | 主图确实使用上传照片；标题、人物与局部区块形成清楚层次；主体位置和取景适合该照片 |
| 多图适配 | 一次上传选定的两张照片；分别把两张设为主图 | 素材栏保持各张照片的身份；辅图与局部图绑定正确；能辨认不同素材，槽位轮换不会全部退回同一示范图 |
| 总 REMIX 保留上传 | 在单图和多图场景中连续点击总 REMIX，循环经过已提供的模板并回到待验收模板 | 主图身份与上传素材池保留；每张图仍可追溯到原图；切换排版与滤镜后不会恢复内置示范照片；文件名不影响结果 |
| 裁切与取样 | 检查主图默认取景，调整缩放和横纵裁切；移动索引框、辅图以及对应局部图 | 照片比例正确；没有意外拉伸、空白边或取错图；局部图与原框内容对应，移动和旋转后关联继续有效 |
| 滤镜表现 | 查看模板默认效果；分别改变图案强度、图案尺寸、模糊方向与距离、杂色和渐变映射；把可关闭参数设为 0 或关闭，再撤销、重做 | 效果响应源照片的亮暗与纹理；参数变化可见；关闭操作有效；预览、撤销和重做一致；透明边缘无意外黑边 |
| 人物可读性 | 以 FIT 看整体，再放大看脸部、手部、轮廓和服装；与原图对照 | 主体仍容易辨认；面部与重要轮廓有足够层次；强处理局部不会同时淹没人物和标题；深色衣物与亮部细节仍可分辨 |
| 导出 | 保存当前默认分辨率 PNG；对代表性样本再选择一个更高分辨率导出；打开实际 PNG 检查 | 文件可打开，像素尺寸与所选规格一致；人物、文字、取样框、局部图和图层关系与预览一致；工作区缩放不改变导出构图 |

若模板需要手动调整才能适配某张照片，记录调整项及前后效果。默认参数的结果与调整后的结果分别保存，方便判断问题来自照片条件、模板默认值还是交互行为。

## 不同照片条件的覆盖

根据实际图库填写覆盖情况；某种条件在图库中不存在时，标为“图库未覆盖”，并说明验收范围。

| 条件 | 重点检查 |
| --- | --- |
| 明亮、柔光、暗光或强反差 | 黑白与双色映射是否保留中间调；亮部是否丢失层次；暗部是否连成难以辨认的整块 |
| 干净背景、复杂背景或与主体明度接近的背景 | 人物是否从背景中清楚分离；底图边缘融合是否自然；局部纹理是否抢走主体焦点 |
| 浅色衣物、深色衣物或有图案和细密纹理的服装 | 半调、位图与杂色是否保留必要信息；衣物是否成为无法辨认的噪点或固定图案 |
| 近景、半身、全身，以及主体偏左、偏右或居中 | 默认裁切是否适合主体；脸部和手部是否被意外切掉；索引框是否采到有意义的内容 |
| 竖图、横图或不同原图尺寸 | Cover 裁切与素材卡片是否保持比例；局部放大是否有足够清晰度；布局是否需要重新适配 |

这些条件是待检查的样本维度，不代表压缩包已经包含对应照片。
